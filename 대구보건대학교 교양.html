HTML, CSS, JavaScript를 이용하여 스네이크 게임 웹앱을 만들어 줘. 다음 조건을 지켜 줘. 웹브라우저에서 실행되는 스네이크 게임을 만들어 줘. 게임 화면은 20×20칸의 격자 형태로 구성해 줘. PC에서는 키보드 방향키로 뱀을 움직일 수 있도록 해 줘. 스마트폰과 태블릿에서는 화면에 표시되는 터치 방향 버튼으로 뱀을 움직일 수 있도록 해 줘. 뱀은 일정한 속도로 자동 이동하도록 해 줘. 화면에 먹이를 무작위 위치에 표시해 줘. 뱀이 먹이를 먹으면 길이가 늘어나고 점수가 10점 증가하도록 해 줘. 벽이나 자신의 몸에 충돌하면 게임이 종료되도록 해 줘. 게임 시작, 일시정지, 다시 시작 버튼을 만들어 줘. 현재 점수를 화면 상단에 표시해 줘. 초록색 뱀과 어두운 배경을 사용하여 깔끔한 아케이드 게임 디자인으로 만들어 줘. PC, 스마트폰, 태블릿 화면 크기에 맞게 자동으로 조절되는 반응형 웹앱으로 만들어 줘. 스마트폰에서는 게임 화면과 터치 버튼이 잘 보이고 조작하기 편하도록 해 줘. 방향키를 반대 방향으로 즉시 누르거나 버튼을 반복해서 눌러도 게임이 정상적으로 작동하게 해 줘. HTML, CSS, JavaScript를 모두 하나의 index.html 파일에 작성해 줘. 외부 라이브러리나 별도의 서버 없이 웹브라우저에서 실행되도록 해 줘. 완성된 게임을 실행하거나 미리 보는 방법도 알려 줘.
